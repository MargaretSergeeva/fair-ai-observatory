# Fair AI Observatory — Concept Overview

Fair AI Observatory is an interactive concept for an EU AI Act-oriented fairness and robustness workflow for high-risk ML systems. The reference use case is consumer credit scoring.

The product idea is to connect configuration, deterministic model evaluation, human review, audit history, and compliance-document samples in one traceable workflow.

## What the prototype demonstrates

The current React application demonstrates:

1. a guided dataset-configuration conversation;
2. protected-attribute and risk-tier review;
3. a simulated deterministic pipeline;
4. before/after fairness and performance results;
5. an Article 15 robustness finding;
6. a sample decision log and stakeholder review;
7. a target architecture for future implementation;
8. a separate reproducible run against the public UCI German Credit dataset.

## Two evidence layers

### Synthetic concept scenario

Act 1 and Act 2 use scripted values for a synthetic `german_credit_sample.csv` scenario. This layer demonstrates intended product behavior when a fairness violation triggers mitigation.

It does not upload a CSV, call an LLM, execute Airflow, or calculate the displayed fairness metrics at runtime.

### Real UCI reference run

The `UCI Reference Run` view uses the machine-readable artifact generated by the repository's Python reference-audit script. It demonstrates that the baseline and existing robustness code can run against a real public dataset.

The real run does not reproduce the synthetic scenario's gender disparity. Gender thresholds pass, while the foreign-worker proxy and equalized-odds checks expose separate findings. The foreign-worker comparison has only 13 minority-group test rows, so it is an unstable signal. Fairlearn mitigation improves one ratio but remains incomplete, and boundary sensitivity fails.

## Human authority boundary

The concept treats agents and automated checks as proposal and evidence-generation mechanisms. Methodology approval, deployment approval, overrides, remediation decisions, and regulatory interpretation remain human responsibilities.
